# CognitiveZip VS Code Extension

Explore and semantically query `.czip` archives directly in VS Code **without decompressing them to disk**!

## Features

- **Zero-Extraction Browsing:** Right-click any `.czip` archive and browse its contents as a virtual file tree.
- **Selective File Viewing:** Open and inspect code files directly in the editor from inside compressed storage.
- **In-Archive Semantic Search:** Run natural language queries to locate specific logic, secrets, or configurations in sub-milliseconds.

## Requirements

Requires the `czip` CLI or `python -m cognitive_zip.cli` available on your system path.
