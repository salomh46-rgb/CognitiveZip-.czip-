One Format. Infinite Integrations.

Use CognitiveZip from your terminal, in your Python pipelines, with autonomous AI agents, or inside VS Code.

# 1. Pack directory with semantic indexing:
$ czip pack ./my_project -o my_project.czip
# 2. Query in 0.05ms without extracting:
$ czip query my_project.czip "stripe payment webhook"
# 3. Stream a single file directly into terminal:
$ czip cat my_project.czip src/auth/jwt.py
# Direct Zero-Extraction Python SDK API
from cognitive_zip import CognitiveZipReader

reader = CognitiveZipReader("my_project.czip")

# 1. Sub-millisecond natural language query
results = reader.query("stripe webhook payment", top_k=3)
for r in results:
    print(f"Match: {r.file_path}:{r.line_number} -> {r.best_snippet}")

# 2. Selectively decompress one file directly into RAM buffer
code_text = reader.read_text("src/auth/jwt.py")
# Add to mcp_config.json for Claude, Cursor, and Antigravity:
{
  "mcpServers": {
    "cognitive-zip": {
      "command": "python",
      "args": ["-m", "cognitive_zip.cli", "mcp"]
    }
  }
}
